### Ressources

* **Code et fichiers** : tout est sur mon dépôt GitHub [noskipws](https://github.com/paguielng/noskipws).
* **Tutoriel de montage** : le site [Low Orbit](https://low-orbit.net/freenove-robot-dog-kit-for-raspberry-pi) détaille toute l'installation.
* **Modèles 3D** : les pièces viennent de [GrabCAD](https://grabcad.com/library/freenove-12dof-tiny-robotdog-quadruped-laser-cutted-1) ; l'arborescence détaillée de chaque pièce que j'ai préparée est dans le [même dépôt](https://github.com/paguielng/noskipws/tree/main/3dmodels).

Le kit, son code et ses circuits sont publiés par Freenove sous licence [Creative Commons BY-NC-SA 3.0](http://creativecommons.org/licenses/by-nc-sa/3.0/).
