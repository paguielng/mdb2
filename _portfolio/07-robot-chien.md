## L'objectif

Monter et faire marcher un robot quadrupède programmable à partir du kit Freenove pour Raspberry Pi.

## Ce que j'ai fait

J'ai rassemblé dans mon dépôt GitHub le code du robot et une arborescence détaillée des pièces 3D de chaque étape d'assemblage, à partir des modèles publiés sur GrabCAD.
